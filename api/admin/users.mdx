## Overview

Manage user accounts including creation, updates, and role assignments. User management is restricted to administrators.

<Warning>
  Only users with `admin` role can create, update, or delete users. Other roles have read-only access to basic user information.
</Warning>

## Authentication

Requires valid JWT token.

```
Authorization: Bearer <token>
```

## List All Users

### GET /api/users

<CodeGroup>
```bash cURL
curl -X GET http://localhost:3001/api/users \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const getUsers = async () => {
  const response = await fetch('http://localhost:3001/api/users', {
    headers: { 'Authorization': `Bearer ${getToken()}` }
  });
  return await response.json();
};
```

```typescript TypeScript
import { Usuario } from './types';

const getUsers = async (): Promise<Usuario[]> => {
  const response = await fetch('http://localhost:3001/api/users', {
    headers: { 'Authorization': `Bearer ${getToken()}` }
  });
  
  if (!response.ok) {
    throw new Error('Failed to fetch users');
  }
  
  return await response.json();
};
```
</CodeGroup>

### Response Fields

<Note>

</Note>

<ResponseField name="nombre" type="string">

</ResponseField>

</ResponseField>

<ResponseField name="gafete" type="string">

</ResponseField>

## Create User

### POST /api/users

<Note>
  **Admin Only:** Only users with `admin` role can create new users.
</Note>

### Request Body

<ParamField body="nombre" type="string" required>
  First name
</ParamField>

<ParamField body="apellido" type="string" required>
  Last name
</ParamField>

<ParamField body="gafete" type="string" required>
  Badge number (must be unique)
</ParamField>

<ParamField body="turno" type="string" required>
  Shift assignment
</ParamField>

<ParamField body="area" type="string" required>
  Area assignment
</ParamField>

<ParamField body="tipo" type="string" required>
  Role: `admin`, `calidad`, `supervisor`, `operador`
</ParamField>

<ParamField body="contra" type="string" required>
  Password (will be bcrypt hashed)
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST http://localhost:3001/api/users \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "nombre": "Carlos",
    "apellido": "Ramírez",
    "gafete": "12345",
    "turno": "A",
    "area": "Ensamble",
    "tipo": "supervisor",
    "contra": "temporal123"
  }'
```

```javascript JavaScript
const createUser = async (userData) => {
  const response = await fetch('http://localhost:3001/api/users', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${getToken()}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(userData)
  });
  
  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.error);
  }
  
  return await response.json();
};
```

```typescript TypeScript
interface CreateUserRequest {
  nombre: string;
  apellido: string;
  gafete: string;
  turno: string;
  area: string;
  tipo: 'admin' | 'calidad' | 'supervisor' | 'operador';
  contra: string;
}

const createUser = async (userData: CreateUserRequest): Promise<Usuario> => {
  const response = await fetch('http://localhost:3001/api/users', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${getToken()}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(userData)
  });
  
  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.error || 'Failed to create user');
  }
  
  return await response.json();
};
```
</CodeGroup>

### Response (201 Created)

```json
{
  "id": 15,
  "nombre": "Carlos",
  "apellido": "Ramírez",
  "gafete": "12345",
  "turno": "A",
  "area": "Ensamble",
  "tipo": "supervisor",
  "activo": 1
}
```

### Errors

**400 Bad Request - Duplicate Badge**

```json
{
  "error": "El gafete ya existe"
}
```

**403 Forbidden**

```json
{
  "error": "Sin permisos suficientes"
}
```

## Update User

### PUT /api/users/:id

<Note>
  **Admin Only:** Only administrators can update user accounts.
</Note>

### Request Body (All Optional)

<ParamField body="nombre" type="string">
  First name
</ParamField>

<ParamField body="apellido" type="string">
  Last name
</ParamField>

<ParamField body="gafete" type="string">
  Badge number
</ParamField>

<ParamField body="turno" type="string">
  Shift assignment
</ParamField>

<ParamField body="area" type="string">
  Area assignment
</ParamField>

<ParamField body="tipo" type="string">
  Role
</ParamField>

<ParamField body="contra" type="string">
  New password (will be hashed)
</ParamField>

<ParamField body="activo" type="number">
  Status (1 = active, 0 = inactive)
</ParamField>

<CodeGroup>
```bash cURL
curl -X PUT http://localhost:3001/api/users/15 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"area": "Moldeo", "turno": "B"}'
```

```javascript JavaScript
const updateUser = async (userId, updates) => {
  const response = await fetch(`http://localhost:3001/api/users/${userId}`, {
    method: 'PUT',
    headers: {
      'Authorization': `Bearer ${getToken()}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(updates)
  });
  
  return await response.json();
};

// Change user's shift and area
await updateUser(15, { area: 'Moldeo', turno: 'B' });

// Reset password
await updateUser(15, { contra: 'newPassword123' });

// Deactivate user
await updateUser(15, { activo: 0 });
```
</CodeGroup>

### Response (200 OK)

```json
{
  "success": true
}
```

## Delete User

### DELETE /api/users/:id

<Warning>
  **Soft Delete:** Users are deactivated (`activo = 0`) rather than physically deleted. They cannot delete their own account.
</Warning>

```bash
curl -X DELETE http://localhost:3001/api/users/15 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Response (200 OK)

```json
{
  "success": true
}
```

### Error (400 Bad Request)

```json
{
  "error": "No puedes desactivar tu propia cuenta"
}
```
