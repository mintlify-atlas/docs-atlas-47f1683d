## Overview

Retrieve comprehensive scrap statistics including today, week, and month totals, top areas, top failures, trends, and aggregations. This endpoint powers the dashboard view.

## Authentication

Requires valid JWT token.

```
Authorization: Bearer <token>
```

## Query Parameters

No query parameters required. The endpoint automatically calculates:
- Today's data (current date)
- Last 7 days data
- Last 30 days data

## Request Example

<CodeGroup>
```bash cURL
curl -X GET http://localhost:3001/api/scrap/stats \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```javascript JavaScript
const getStats = async (token) => {
  const response = await fetch('http://localhost:3001/api/scrap/stats', {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  return response.json();
};
```

```typescript TypeScript
interface ScrapStats {
  hoy: { cantidad: number; costo: number };
  semana: { cantidad: number; costo: number };
  mes: { cantidad: number; costo: number };
  topAreaHoy: { AREA: string; cantidad: number };
  topFallaHoy: { MODO_FALLA: string; cantidad: number };
  porArea: Array<{ AREA: string; cantidad: number; costo: number }>;
  porTurno: Array<{ TURNO: string; cantidad: number; costo: number }>;
  porCadena: Array<{ CADENA: string; cantidad: number; costo: number }>;
  tendencia: Array<{ fecha: string; cantidad: number; costo: number }>;
  topPartes: Array<{ NP: string; cantidad: number; costo: number }>;
  topFallas: Array<{ MODO_FALLA: string; cantidad: number }>;
  totalRegistros: number;
}

const getStats = async (token: string): Promise<ScrapStats> => {
  const response = await fetch('http://localhost:3001/api/scrap/stats', {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  return response.json();
};
```
</CodeGroup>

## Use Cases

<AccordionGroup>
  <Accordion title="Dashboard KPI Cards">
    Use `hoy`, `semana`, and `mes` fields to display KPI cards showing today's metrics, weekly trends, and monthly totals.
  </Accordion>
  
  <Accordion title="Chart Visualizations">
    Use `porArea`, `porTurno`, `porCadena` for pie/bar charts. Use `tendencia` for line charts showing daily trends.
  </Accordion>
  
  <Accordion title="Top Offenders Widget">
    Display `topPartes` and `topFallas` in ranked lists to identify problematic parts and common failure modes.
  </Accordion>
  
  <Accordion title="Quick Insights">
    Use `topAreaHoy` and `topFallaHoy` to show which area and failure mode are most problematic today.
  </Accordion>
</AccordionGroup>
