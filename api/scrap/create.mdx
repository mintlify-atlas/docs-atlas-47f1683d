## Overview

Create a new scrap record (pesaje) in the system. This endpoint automatically detects available columns in the database and only inserts supported fields.

<Note>
  All authenticated users can create scrap records. The endpoint automatically sets `FECHA_REGISTRO` to the current timestamp if not provided.
</Note>

## Authentication

Requires valid JWT token in the Authorization header.

```
Authorization: Bearer <token>
```

```typescript TypeScript
import { Pesaje } from './types';

interface CreateScrapRequest {
  AREA: string;
  NP: string;
  MATERIAL: string;
  PESO?: number;
  COSTO?: number;
  CADENA: string;
  TURNO: string;
  TIPO: string;
  SUPERVISOR: string;
  FECHA_REGISTRO?: string;
  TOTAL_PZAS?: string;
  MODO_FALLA?: string;
  USUARIO_ID?: number;
  COMENTARIOS?: string;
  FOTO?: string;
  CATEGORIA?: string;
  UNIDAD?: string;
  CADENA_ID?: number;
  LINEA_ID?: number;
  LINEA?: string;
}

const createScrap = async (data: CreateScrapRequest): Promise<Pesaje> => {
  const response = await fetch('http://localhost:3001/api/scrap', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${getToken()}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(data)
  });
  
  if (!response.ok) {
    throw new Error('Failed to create scrap record');
  }
  
  return await response.json();
};
```

## Implementation Notes

<Note>
  **Dynamic Column Detection:** The endpoint queries the database schema to detect available columns and only inserts supported fields. This ensures backward compatibility with different database versions.
</Note>

<Note>
  **Automatic Timestamp:** If `FECHA_REGISTRO` is not provided, it defaults to the current server time using `NOW()`.
</Note>

<Warning>
  **Photo Size Limit:** The API has a 50MB body limit. Base64 encoded photos should be compressed before upload.
</Warning>

<Warning>
  **Soft Delete:** Records are marked as deleted (`ELIMINADO = 1`) rather than being physically removed from the database.
</Warning>
