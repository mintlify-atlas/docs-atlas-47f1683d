## Overview

Update an existing scrap record. This endpoint is not directly implemented in the current route files but follows the RESTful pattern expected by the frontend API client.

<Warning>
  This endpoint may require specific permissions based on the user's role and the age of the record. Typically, only records from the current day can be edited by supervisors, while admins and quality control can edit any record.
</Warning>

## Authentication

Requires valid JWT token in the Authorization header.

```
Authorization: Bearer <token>
```

## Path Parameters

<ParamField path="id" type="number" required>
  The unique ID of the scrap record to update
</ParamField>

## Request Example

<CodeGroup>
```bash cURL
curl -X PUT http://localhost:3001/api/scrap/1234 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "COSTO": 52.50,
    "TOTAL_PZAS": "175",
    "COMENTARIOS": "Costo actualizado después de revisión"
  }'
```

```javascript JavaScript
const updateScrap = async (id, updates) => {
  const response = await fetch(`http://localhost:3001/api/scrap/${id}`, {
    method: 'PUT',
    headers: {
      'Authorization': `Bearer ${getToken()}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(updates)
  });
  
  return await response.json();
};

// Update cost and quantity
await updateScrap(1234, {
  COSTO: 52.50,
  TOTAL_PZAS: '175',
  COMENTARIOS: 'Costo actualizado después de revisión'
});
```

```typescript TypeScript
import { Pesaje } from './types';

type ScrapUpdate = Partial<Omit<Pesaje, 'ID' | 'FECHA_REGISTRO' | 'ELIMINADO'>>;

const updateScrap = async (id: number, updates: ScrapUpdate): Promise<{ success: boolean }> => {
  const response = await fetch(
    `http://localhost:3001/api/scrap/${id}`,
    {
      method: 'PUT',
      headers: {
        'Authorization': `Bearer ${getToken()}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(updates)
    }
  );
  
  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.error || 'Failed to update record');
  }
  
  return await response.json();
};
```
</CodeGroup>

<Note>
  Updates are logged in the `auditoria` table with:
  - Action: `'editar'`
  - Entity: `'pesaje'`
  - Entity ID: Record ID
  - User ID: ID of user making the change
  - Changes: JSON object of updated fields

## Implementation Example

### Frontend Update Form

```typescript
const handleUpdate = async (recordId: number, formData: ScrapUpdate) => {
  try {
    // Validate changes
    if (Object.keys(formData).length === 0) {
      throw new Error('No hay cambios para guardar');
    }
    
    // Confirm with user
    if (!confirm('¿Guardar cambios en este registro?')) {
      return;
    }
    
    // Send update
    const result = await updateScrap(recordId, formData);
    
    if (result.success) {
      alert('Registro actualizado exitosamente');
      // Reload data or update local state
    }
  } catch (error) {
    console.error('Error updating record:', error);
    alert(`Error: ${error.message}`);
  }
};
```

### Optimistic Update Pattern

```typescript
const optimisticUpdate = async (recordId: number, updates: ScrapUpdate) => {
  // Store original data
  const original = { ...currentRecord };
  
  // Update UI immediately
  setCurrentRecord({ ...currentRecord, ...updates });
  
  try {
    // Send to server
    await updateScrap(recordId, updates);
  } catch (error) {
    // Revert on error
    setCurrentRecord(original);
    throw error;
  }
};
```

## Best Practices

<Warning>
  **Concurrency:** Implement optimistic locking or version numbers to prevent overwriting changes made by other users.
</Warning>

<Note>
  **Partial Updates:** Only send fields that have changed to minimize data transfer and reduce chance of conflicts.
</Note>

<Note>
  **Validation:** Validate data on both client and server side. Check constraints like required fields, data types, and value ranges.
</Note>
